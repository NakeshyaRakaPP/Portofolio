PORTFOLIO LOGO BRAND VIEWER + 5 CASE STUDIES

HOW TO APPLY
1. Extract this ZIP into the root of the existing Portofolio project.
2. Allow matching files to be replaced/merged.
3. This is a patch ZIP: files not present in this ZIP are NOT meant to be deleted.
4. Keep the existing five logo PNG files in src/img/.
5. Replace the placeholder JPGs in src/img/logo-projects/<brand>/ with your final mockups using the exact same filenames.
6. Run: npm run build
